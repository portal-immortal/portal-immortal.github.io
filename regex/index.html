Notepad++ Examplesfind & replace

Format: Input → Find → Replace → Output. Search Mode di Notepad++: Regular expression.

1. Tambah tanda kutip di akhir baris Regular expression

Menambahkan single quote di akhir setiap baris.

Input
ABC
DEF
GHI
Find
$
Replace
'
Output
ABC'
DEF'
GHI'

2. Format baris jadi list SQL Regular expression

Menambahkan single quote + comma untuk SQL.

Input
ABC
DEF
GHI
Find
^(.+)$
Replace
'\1',
Output
'ABC',
'DEF',
'GHI',

3. Hapus whitespace di awal baris Regular expression

Membersihkan indentasi/spasi di awal setiap baris.

Find
^\s+
Replace
(kosong)

4. Hapus whitespace di akhir baris Regular expression

Membersihkan trailing space sebelum baris berakhir.

Find
\s+$
Replace
(kosong)

5. Cari baris kosong Regular expression

Berguna untuk highlight atau menghapus baris kosong di file.

Find
^$

6. Ubah format tanggal Regular expression

Dari format ISO (YYYY-MM-DD) ke format DD/MM/YYYY.

Input
2026-08-14
Find
(\d{4})-(\d{2})-(\d{2})
Replace
\3/\2/\1
Output
14/08/2026

    Mulai Belajar dari Siniroadmap

    1. Hafalkan ^ dan $
    2. Hafalkan \d dan \s
    3. Pahami +, *, dan ?
    4. Pelajari [] dan ()
    5. Pelajari capture group dan \1, \2
    6. Mulai membuat pola sendiri

    Regex tidak perlu langsung dihafalkan semuanya — lebih baik belajar dari pola yang sering dipakai, lalu tambahkan pelan-pelan lewat playground di atas.
